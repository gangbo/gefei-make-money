# 个人开发者实用资料库

这个项目主要收集、整理对个人开发者和独立开发者有用的信息，覆盖从发掘需求、验证产品到运营推广、外联获客和商业化的过程。

资料来自社区讨论、经验分享、网页、截图和实际研究。我们把零散信息整理成便于阅读、查找和复用的文档，为后续讨论和产品决策提供参考，而不只是收藏链接。

## 收集方向

- **需求发掘**：去哪些网站找需求，如何从搜索趋势、竞品、用户评论和真实付费行为中发现机会。
- **产品验证**：判断市场规模、竞争程度、技术难度和付费意愿，确定值得尝试的最小产品。
- **运营与增长**：产品上线、用户反馈、内容运营、SEO、关键词研究和增长复盘。
- **外联与推广**：联系潜在用户、发送外联邮件、寻求合作、提交产品到相关平台，以及外链建设的方法与经验。
- **盈利与商业化**：定价、收费方式、转化、留存，以及获得第一笔收入的实践案例。
- **工具与工作流**：帮助个人开发者提高研究、开发和运营效率的工具、清单与可复用流程。

以上是持续收集的范围。目前资料以需求发掘、出海运营和 SEO 选品研究为主，外联等专题会继续补充。本项目是文档资料库，不是自动发送邮件或执行推广的应用。

## 如何使用

1. 找方向时，先阅读需求发掘方法和网站入口整理。
2. 准备上线和推广时，参考运营、商业化及相关实践案例。
3. 研究具体机会时，同时查看结论、原始资料、数据日期和适用范围。
4. 将有价值的新信息继续保存到 `docs/`，并在本文件中补充阅读入口。

## 整理原则

- 保留来源、整理日期和必要背景，方便追溯。
- 合并重复内容，优先留下具体方法、操作入口、案例和限制。
- 区分原作者观点、数据事实与整理者的推断。
- 明确记录无法确认、未展开或可能过时的信息，不补写成确定结论。
- 将经验用于提出假设，再通过真实用户、使用和付款行为验证。

项目持续更新，目标是积累一套个人开发者能够查得到、看得懂、用得上的实用知识库。
