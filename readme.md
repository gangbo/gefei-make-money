## 使用原则

资料按来源和日期保存，候选按稳定 ID 跟进。每次研究结束更新来源、候选、决策和进度。原始导出、人工摘要、厂商宣传、个人观点与分析推断明确区分；缺失资料写明，不补成已采集。

同一历史周期不重复抓取；做当前决策时按需要刷新价格、功能或最新月份，并保留旧记录。本项目不自动外联、发帖或执行推广。
