## 0. 核心思路：先看「市场在关注什么」，不先想「我要做什么产品」

- 3 月新词赛冠军：思维从「我要做什么产品」变成「先看市场在关注什么」。→ [存档](../posts/2026年3月新词比赛第1名分享：入群2天半，找到爆款词，收入2000美金-2026-04-14.md) / https://new.web.cafe/topic/wr0cxwogic
- 哥飞总结群友赚钱共性：「主动挖掘真实需求，而不是被动做命题作文」。→ [存档](../posts/我的4000人出海创业社群里，靠SEO赚到钱的人都做对了什么？-2025-12-21.md) / https://new.web.cafe/topic/2mz756r3yb
- 社群里「需求」≈ 有人在 Google 搜的**关键词**。两大流派：
  - **新词**：刚出现 / 热度飙升 / 竞争空白；反馈快（常 48h～1 周）。
  - **老词**：稳定搜索量；反馈慢（两周～两个月），但结果更确定——已能看到别人怎么变现。
- 谷歌官方长期口径：约 **15% 搜索是全新词**；近年量级约每年 5 万亿次搜索 → 每天约 **20 亿次全新搜索曝光**（哥飞小课堂）。新词站的第一名窗口真实存在。→ [存档](../posts/2026.07.12-哥飞小课堂-梳理-dragganaitool.com-讲-2026-07-12.md) / https://new.web.cafe/tutorial/detail/1xldegdtlt

## 1. 方法总览（哥飞北京分享实录 · 需求挖掘方法大全）

来源：[哥飞：那些年我们用过的需求挖掘方法大全](../posts/哥飞-：那些年我们用过的需求挖掘方法大全-2026-07-20.md)（含约 51 分钟逐字稿）/ https://new.web.cafe/tutorial/detail/4cw34231cx

把社群用过的挖需求方式压成一条**可循环链路**（不要只盯 KD&lt;30）：

| # | 方法 | 怎么做 | 输出 |
|---|---|---|---|
| 1 | **Google 下拉联想** | 搜种子词，看 Suggest；理解「谷歌眼里这个词还连着什么」 | 品牌词下常出现 login / hotline / download 等任务词 |
| 2 | **Suggest → Ads 关键词规划师洗量** | 一批批丢进规划师（左最多约 10、右最多约 200）下载带搜索量的表 | 有量词列表；再看 SERP/KD 找「软柿子」 |
| 3 | **Similarweb 关键词生成器漫游** | 无目的输入任意词；看「平均体量」vs「近 28 天」——28 天明显更大 = 上升词 | 词→站→相似站→再词 |
| 4 | **词找站 / 站找词循环** | 某词第一名专域站 → Top pages / 相似站 → 再拓词；看定价页暴露卖什么权益 | 可复制的品类与变现模型 |
| 5 | **社媒出站流量 + Whois 排序** | Similarweb 看出站；用 bookmarklet 抽域名，按注册时间从新到旧排 | 刚靠社媒起飞的新站 |
| 6 | **支付收银台入站排行** | 看 Stripe / PayPal 等收银台的入站流量（近似订单量相对强弱） | 「真收到钱」的站，不是刷出来的流量 |
| 7 | **Google Trends 飙升** | 种子词（如 AI）→ 相关查询飙升 / Breakout | 新词候选（见方法 A SOP） |
| 8 | **托管子域名雷达** | Similarweb 着陆页看 `*.vercel.app` 等有流量子域（见方法 B） | 有热度但常不懂 SEO 的项目 |
| 9 | **监控 Sitemap / 外链** | 盯频繁上新的老站 sitemap；挖优秀站外链找站长新域名（见方法 C/D） | 别人帮你发现的新词 |

哥飞强调：**找词时不要太功利**——多看站、定价页、流量来源、页面结构，才能建立「出海视野」；只筛 KD 会把河捞干。

## 2. 方法 A：Google Trends 找新词（SOP + 判断力）

### A1. 冠军实操（公开全文）

- 输入种子词 → 右侧「相关查询 → 飙升」；**看不懂的词就是候选**。
- 冠军在相关查询第 2 页发现词 → 次日升到第 1 页第 8 → 中午第 4 → 立刻 Google：Reddit/X 讨论多、正经网站少、.com 未注册 → 11:50 买域名，2 小时上线 → 24h 26 万曝光 / 10 万点击。  
  → [存档](../posts/2026年3月新词比赛第1名分享：入群2天半，找到爆款词，收入2000美金-2026-04-14.md)
- 2 月冠军：每天固定刷 Trends；游戏词当天飙升 + 域名空 + 首页几乎无相关站 → 30 分钟上站。  
  → [存档](../posts/2026年2月份新词新站比赛复盘：死磕游戏站-2026-03-10.md)

### A2. 明月的日常 SOP（VIP 全文）

→ [谷歌趋势找词：判断力只能在重复中形成](../posts/谷歌趋势找词：判断力只能在重复中形成-2026-09-02.md) / https://new.web.cafe/topic/5kddyouw59

1. Trends 输入词根（例：Maker），时间窗 **7 天**
2. 从「搜索量上升的相关查询」里选一个词
3. 点开该词，看 **7 天 / 30 天 / 12 个月** 曲线，判断是否新词（目标：**长长的、尖尖的**趋势图）
4. 问 AI：搜索意图是什么
5. Google 搜该词，点开首页前 3 站，记下来「做什么」——下次可过滤
6. 重复

**量级预期（社群口径）：** 良辰美一天看几千页；哥飞说每天看约 **100 个关键词、1000 个网站**。判断力只能在重复中形成，无法跳过。

**评论区提速技巧（古月喵）：** 优先点 **飙升 / Breakout**，或涨幅极大（如 3000%）的词，不必每个相关查询都点开。

### A3. 新手 8 步课里的「免费三件套」

→ [新手向 AI 新词站白话课](../posts/新手向-AI-新词站白话课：把哥飞讲的找词、建站、上线理成-8-步-+-站长模拟器-2026-10-27.md) / https://new.web.cafe/topic/4hnivviyy9  

找新词三件套：**Google Trends + Google 搜索 + 关键词规划师**；新词还没数据时，可用 **GPTs 商店对话量** 当尺子粗估热度（哥飞实录里也讲过刷对话量抢 GPTs 排名的历史玩法，今作背景了解即可）。

## 3. 方法 B：托管平台子域名挖「已验证需求」（Vercel 法等）

### B1. 哥飞原帖 SOP（VIP 全文）

→ [如何利用 Vercel.app 等…挖新网站、新需求](../posts/如何利用-Vercel.app-等网站托管平台子域名来挖掘最新有新增流量的新网站-2026-05-12.md) / https://new.web.cafe/topic/z0vu7k8587

**原理**

1. 部署后 Vercel 会给 `xxx.vercel.app` 临时域名；不少人懒得买域名，直接传播子域名。
2. 用 **Similarweb → 关键词研究 → 着陆页**，看挂在 `vercel.app` 下、**已有流量**的子域名（Semrush 子域名能力已收到更贵套餐，哥飞现多用 Similarweb）。
3. 这类站通常 **不懂 SEO** → 你用成熟 SEO 做独立域名站 = **降维打击**。
4. **不必找「刚上线」的站**（一开始没流量）；找**正在起量**的。
5. 矿还在长：`vercel.app` 总流量持续涨 = 供给还在增加。

**同理可扫的托管后缀（哥飞列举）**

`netlify.app` / `netlify.com` / `pages.dev` / `web.app` / `firebaseapp.com` / `surge.sh` / `onrender.com` / `ondigitalocean.app` / `amplifyapp.com` / `azurestaticapps.net` / `deno.dev` / `herokuapp.com` / `railway.app` / `fly.dev` / `koyeb.app` / `northflank.app` / `code.run` / `zeabur.app` / `sevalla.app` / `glitch.me` / `replit.app` / `bolt.host` / `lovable.app` / `bubbleapps.io` / `softr.app`；以及 **GitHub Pages：`github.io`**。

也可：`site:vercel.app` + 关键词、工具目录、GitHub README、PH、Reddit 观察早期项目。

### B2. 实战：陈丽新（5 月第 3 名 · 12 万 UV）

→ [5 月新词比赛第3名复盘](../posts/5-月新词比赛第3-名复盘：我怎么从一个-Vercel-子域名，做出一个月-12-2026-06-14.md) / https://new.web.cafe/topic/ahyoanddkm

**发现 → 判断清单（可复用）**

1. Similarweb 看 `vercel.app` 起量着陆页（Chrome Ask Gemini 辅助总结）
2. Trends 确认仍是新词且趋势上升
3. 把「词 + Similarweb 数据 + 原站」扔给 AI 员工做系统调研：起源、意图、热点持续性、SERP 供给、域名注册、竞品、实现复杂度
4. 决定做的理由示例：新瓶装旧酒（猜色游戏有生命力）+ 前几页有效页很少 + 实现不难 → **窗口在但要快**
5. 产品三原则：立刻接住需求（首页就能玩）/ 比竞品更好一点 / **当天上线闭环**
6. 基础设施也是增长方案：流量起来后 Vercel 免费额度爆了 → 迁 Cloudflare Pages 等无限静态额度方案

（公开全文对照：野生小虎同一方法 → 30 天 100 万 UV。→ [存档](../posts/第一次做出海-SEO，我用一个练手小游戏-30-天跑到-100-万-UV，290-2026-06-11.md)）

## 4. 方法 C：监控 Sitemap + 横向拓展（dragganaitool 案例）

→ [2026.07.12 哥飞小课堂 · dragganaitool.com](../posts/2026.07.12-哥飞小课堂-梳理-dragganaitool.com-讲-2026-07-12.md) / https://new.web.cafe/tutorial/detail/1xldegdtlt

**Banbri 启发的玩法（2023 起就在用）**

1. 找一批流量大、常上新内页的站（游戏站尤其典型）
2. **跟踪它们的 sitemap**，每出新 URL 就抽关键词
3. 丢进 Trends 验证是否新词、起势够不够猛
4. 是 → 注册域名上新站；也可同时在老站加内页

**新词双开策略（Audi 等）**

- 老站 **内页** 吃初期排名 + 新站 **首页** 吃后期排名  
- 还可在 Medium 等高权重平台发帖 → SERP 里多占几个可控结果

**横向拓展精髓**

- 首页继续死守已验证主词（**不要改首页换词**）
- 每个几乎无竞争的新词开一个内页 → 流量叠加  
- 有流量的内页可再拆成独立站「举全站之力」优化

**案例小结 8 条（哥飞原帖）**

1. 追新词有效  
2. 新词既做内页也上新站  
3. 新词少外链也能排，巩固仍需外链  
4. 可借高权重平台发内容占位  
5. 横向拓展让老站续命  
6. 监控频繁上新的老站 sitemap  
7. Trends 验量 + 挖相关新词  
8. 任何类型站都可加博客：内页流量 + 卖客座软文  

**外链侧挖新站：** 挖优秀站外链 → 发现站长新注册域名（多个年度赛获奖者提到）。

## 5. 方法 D：四层漏斗选词（新手找词指南 · Jade）

→ [新手找词指南：从0到1](../posts/新手找词指南：从0到1，找到能赚钱的关键词-2026-07-24.md) / https://new.web.cafe/topic/bl2xzrgkwm

**好词三条件：** 有人搜 / 你能打得进 SERP / 跟你的站方向一致。

**路径：** 需求自上而下 · 竞品自下而上 · 工具辅助 —— 文中主讲后两者。

### 漏斗（便宜工具先筛，Ahrefs 留到最后）

1. **发现候选站**  
   - 哥飞 SEO Agent 要站（库内数据，需自己复核）  
   - **Stripe 等导流榜**（能送进收银台 ≈ 真收款）  
   - 赢家反推：搜赚钱方向词看前排站  
   - Similarweb Similar Sites  
2. **粗筛**  
   - 月访过低（如 &lt;1000）丢掉  
   - 域龄：优先 **3～12 个月「年轻 + 有量」**；5 年以上老站难追上  
   - 三道筛：支付中间页丢掉 / 纯品牌火爆站只当灵感 / **靠通用词吃流量**的才是词矿  
3. **深挖：是不是真 SEO 词矿**  
   - 先分类型：工具型 / 内容型（值得反推）vs 产品型（多作启发）  
   - **流量 ÷ 词数**：高流量+多词 = SEO 矿；高流量+少词 = 投流站  
   - 关键词总数曲线：一年内 0→几千 = 新星；从几千掉到几百 = 见顶  
   - 最优对象：**域龄新 + 词数在涨**  
4. **判决（才开 Ahrefs）**  
   - Organic Keywords / Top Pages  
   - SERP：竞争强度、特性占位、意图匹配、外链/权威、是否被单站垄断  
   - KD 只作参考，必须结合盘面  

再扩 **关联词圈**：同义说法 → 上下游功能词 → 相似站再反推一轮。

**三句口诀：** 多工具交叉；最贵工具留到最后；流量虚、词实、收款硬。

## 6. 方法 E：社区抱怨调研 Skill（输入一个网站 → 14 问）

→ [分享一个自己的 skill…](../posts/分享一个自己的skill，输入一个网站，全网调研需求群体的真实讨论和抱怨，分析切-2026-08-20.md) / https://new.web.cafe/topic/6ccjclfd2d  
GitHub：https://github.com/cxf37905-max/research-website-demand

**用途：** 给定竞品/目标站 URL，全网收集真实讨论（Reddit、HN、官方社区、Trustpilot、G2、扩展商店等），用故事还原用户世界 + 固定 **14 问**，找**未被满足的切入点**。

**14 问骨架（可当调研模板）**

1. 这是什么站  
2. 用户群体具体是谁  
3. 为什么用  
4. 什么场景什么问题  
5. 需求产生原因  
6. 涉及什么利益  
7. 为什么付费  
8. 没有产品时怎么凑合、代价是什么  
9. Google 会搜哪些中英文核心词  
10. 除了 Google 还聚集在哪  
11. 用后评价（无独立证据就标未知，不编）  
12. 市面产品池  
13. 各产品功能/定价/口碑对照  
14. **现有产品没覆盖的痛点 → 切入点**

**案例结论模式（saveto.ai 示例）：** 不要再做一个「更全的万能摘要器」；强机会在可核验理解、真实世界音频流水线、主动学习型产品、可信定价/隐私关系等。

公开信号补充：SERP 全是 Reddit/X 讨论、正经站很少 = 需求真实 + 供给空白（3 月冠军同理）。

## 8. 判断一个词能不能做（检查清单）

综合小虎、陈丽新、Jade、2 月冠军：

1. **趋势还在不在**：总趋势 + 24h/4h；最怕追尾巴；分析为何火（社媒带火则后劲难料）
2. **SERP 竞争**：只看第一页；前排是内页/子域/小站 = 机会；前排 DR 个位数 = 利好
3. **域名**：.com / 好后缀 / typo 是否被抢光；抢光 + 前排高权重 ≈ 窗口关
4. **意图是否被满足**：现有结果是否真正满足（小虎：别人只有调色卡，没做「回忆童年颜色」）
5. **能否快速交付**：开源/AI 能否当天做出闭环
6. **游戏词经验**：词出现 &gt;30 天且竞品域名已做 &gt;20 天 → 放弃；**Semrush KD 低 ≠ 能做**（2 月冠军 KD&lt;30 老游戏词全军覆没）
7. **Jade 加码**：流量÷词数剔投流；域龄新+词涨才优先反推

## 9. 验证需求 → 上线工作流

### 9.1 当天上线闭环（多篇复盘共识）

买域名 → AI 生成最小可用页 → 部署 → GSC + GA → 提交索引（尽量赶欧美活跃时段）。

### 9.2 辞安 8 步顺序（VIP）

找新词 → 收词扩词（9 来源、去重查量分组、**保小图大**、慎同义词陷阱）→ **一页主攻一词**（两词是否同一意图：分别搜比前 10）→ 定结构（核心词首页、第一天只上必须页）→ 做页面（两周后看 GSC 再加精品页）→ 内链成网 + 外链催收录 → 工具/订阅（先算成本再定价）→ 上线验收与优化。

### 9.3 产品与变现注意（陈丽新）

- 先接住用户，再差异化，再完美  
- AdSense 审核严；模板海量相似页易被判低价值  
- 热点游戏站：流量小时保护体验；爆发期可先跑 Monetag/Adsterra 闭环；稳定后再优化广告质量  
- 外链：AI 适合收集/提交/记录，**策略与质量要人把关**；早期低质外链不如少而精的 dofollow  

### 9.4 其他经验（公开 + 标题曾提、现已有全文支撑）

- 先简后繁：登录/支付后置；先打通全流程  
- 可用老站内页试水再独立建站  
- 新词排名常需 2～4 周稳定；哥飞强调看 GSC  
- 只靠一个主词危险：多语言 + typo + 多引擎托底（小虎）

---

## 10. 常见错误

- 追热点无成套打法、靠运气（冠军最终放弃 SBTI，转长期工具）
- 用 KD 低的老词硬上，赛道已卷满
- 只看 Similarweb 大流量就抄词——可能是投流（Jade）
- 监控 sitemap 发现太晚、无信息增量，只能靠疯狂外链（2 月冠军：性价比低）
- 首页改词 / 一页堆太多词 / UGC 污染密度
- 模板批量页导致 AdSense「低价值」
- 基础设施没预案（Vercel 免费额度爆站）
- 技术人沉迷自研两个月无商业价值 → 能买模板就买，先验证流量。→ [万刀复盘](../posts/万刀之阶段性复盘--有秘诀-2026-07-31.md)
- 光看不做：小南姐做了六七十个站才爆一个
- 想跳过「大量点击看趋势」的阶段——判断力练不出来（明月）

## 11. 给 Gary 的可执行日常（更新版）

**每天（找词）**

1. Trends：2～3 个种子词（AI / game / generator / 新模型名）→ 只深挖 **Breakout / 飙升 / 超高涨幅**；对候选跑 7d/30d/12m + AI 意图 + SERP 前三。目标量：能坚持就向「每天几十～一百词」加。
2. Similarweb：扫 `vercel.app`（及 github.io / netlify.app 等）**起量着陆页**；候选丢进第 8 节清单。
3. （可选）盯 5～20 个优质站 sitemap 增量；或从 Stripe 导流榜捞「年轻+有量」真收款站，跑 Jade 四层漏斗。

**发现候选当天**

4. 满足清单 → **当天**最小可用上线，接 GSC/GA；基础设施按峰值预案（别死磕免费额度）。
5. 首页死守主词；后续用横向拓展加内页，不要改首页换赛道。

**一周后**

6. 按 GSC 决定：加内页 / 多语言 / 精外链，或放弃。  
7. 若做工具/SaaS 向：用「抱怨调研 14 问」对标一个竞品站，找可核验切入点，而不是再堆功能。

**对照表**

8. 浏览器打开 [找词总览表](https://new.web.cafe/topic/fqwjbo8sbv) 看图（存档正文薄）；需要练习时打开辞安 [8 步课 + 模拟器](https://claude.ai/artifact/JMBQdS3Y2jCcU652MYtAqP)。
