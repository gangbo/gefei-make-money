# 产品交付可行性：房产照片批处理

## 建议的 MVP 输入输出

- 输入：单张 JPEG/RAW 或 3–5 张 bracketed exposures；一次上传一套房源。
- 输出：MLS-ready JPEG，一套照片保持一致曝光、白平衡和风格。
- 首版能力：HDR 合并、窗景/高光恢复、垂直线和透视矫正、白平衡/relighting、批量预设、前后对比与逐张重做。
- 首版暂缓：虚拟布置、大范围生成式改造、复杂去物体。这些功能更易产生事实失真，也会把产品拉进更拥挤的生成赛道。

## 为什么可交付

- Autoenhance、AutoHDR、Fotello 等已证明浏览器上传、批量处理和按张下载可行。
- HDR、透视、白平衡等任务可由传统计算机视觉与专用模型组合，不必让通用生成模型重画整个房间。
- 一套房源天然形成批次，适合队列处理、额度计费和重试；摄影师又有重复拍摄，复购逻辑强。

## 主要风险

1. 质量一致性：单张看起来好不够，同一房源不同房间必须风格一致。
2. RAW/bracket 支持和大文件上传会增加处理、存储与失败重试成本。
3. 窗景、天空和去物体可能改变房源事实；应默认保守、保留原图、提供操作记录。
4. 按张市场价已经压到约 `$0.29–0.53`，在没有跑出真实处理成本和返工率前，不能承诺更低价格。

## 最小商业验证

- 先收集 100–300 组真实 bracket/室内外样片，建立盲测质量标准。
- 落地页提供 3 张免费水印预览，不先做无限免费。
- 目标客户：每月 5–50 套房源的小型房产摄影工作室，而不是偶尔上传一张照片的房产经纪人。
- 通过 10 位摄影师的真实批次测算：可接受率、人工返工分钟、处理成本、每套节省时间和愿付价格。
- 只有当首轮可接受率 ≥80%、人工复核中位数 ≤2 分钟/套、单位毛利 ≥70%，再扩充自动去物体、twilight 和工作流管理。
