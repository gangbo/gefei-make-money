# D-036：评分地区、精简开发成本与小收益能否值得做

2026-10-03；DEC-062；证据[S-083](../../01-sources/app-store/2026-10-03/site-audit-region-economics.md)，复用S-082。用户允许小盈利项目，条件是成本低。此为条件评估，未授权开发/购买或建立实际预算。

## 判断

中国大陆6个评分属实，同一Site Audit Pro美国约11K、英国约23K。因此不能断言全球只有很少用户，也不能由此推算收入。大陆6评分只是该产品当地采纳偏弱的线索，可能涉及语言、渠道和用途，无法区分原因；没有证据说明做中文就有人买。若目标是海外的小型职业买断工具，可以低成本试；若只做国内，不宜依据美国信号直接开发。

保留D-036为可控交付优先候选，状态待补，不是利润最大或已证实值得重投入。开发是中等复杂度，低的是离线版本的持续计算/服务器现金成本；人时与获客仍可很高。用户月收入容忍水平未给数值，不代替用户确认，但下面列清楚计算条件。

## 精简收费版边界

只做iPhone、小型物业/维修报告：项目/房间、问题标题和备注、多图、箭头/圈选、顺序调整、一个品牌PDF模板、预览/分享、本地保存、文件备份恢复、一次解锁/恢复购买。无需云数据库或逐次AI推理。首版不包含企业权限、协作派单、云同步、自动诊断、复杂签名流程、几十种模板、任意Excel/业务系统集成。用户免费先完成一个完整项目及报告，可验实际输出，不计作已决定收费规则。

## 开发工时：工程估算而非已测结果

假设一名熟悉Swift/iOS发行的开发者、AI辅助、已有Mac/测试iPhone、已有基本组件经验；未查看待开发代码或组件，因此置信度有限。

| 工作 | 估算有效人时 |
| --- | --- |
| 项目/问题/照片导入及基础交互 | 20–30 |
| 基础箭头/圈选、顺序调整 | 8–16 |
| 一个PDF模板、长文字/多图分页与分享 | 12–20 |
| 数据恢复、文件备份导入、图片内存处理 | 8–16 |
| 一次内购/恢复、商店材料与发行配置 | 10–18 |
| 真机断网、大图、后台/异常和导出核对 | 15–25 |
| 合计 | 73–125；规划宜取约80–130 |

界面与基本导出演示可先限12–24有效小时（约2–4工作日），不等同可靠收费产品。正式精简版按约80–130小时/2–4周投入规划，日历还受审核等待/修复与开发熟悉度影响，非交付承诺。AI缩短代码编写，但照片关联错误、数据丢失、恢复和PDF分页仍要验证。维护暂按2–6小时/月作预留假设，用户规模/故障会改变；不是实际测量。

现金：如用户已持有设备与开发者账号，新增硬件/会员边际支出可能低；否则Apple账号$99/年，设备另计。AI订阅若已有也是共享固定费，不能说全成本为0。其他运营工具、推广、税费/退款未知。纯本地无逐次云推理成本，不等于没有成本。

## 买断销售的场景算术

仅作海外美元算例：售价$14.99，已加入适用15%佣金的小企业计划；先忽略地区消费税/退款/广告/维护及所得税。每新增付费者佣金后收入$12.7415。这不是App Store最终实收金额或净利润。

| 每月新增买断客户 | 扣15%平台佣金后的月收入 | 常规30%时同口径收入 |
| ---: | ---: | ---: |
| 20 | $254.83 | $209.86 |
| 50 | $637.08 | $524.65 |
| 100 | $1,274.15 | $1,049.30 |
| 300 | $3,822.45 | $3,147.90 |

新增买断客户不是活跃用户或老用户总数；一次购买不能每月再算一遍。表没有预测我们能取得20/50/100人。

人时机会成本示例：100小时×$20/小时=$2,000（仅算例，不是用户报价）。15%下需累计157单覆盖这$2,000，30%需191单，均未扣其他费用。若真的每月新增20人，无广告/退款/其他支出时约8个月覆盖$2,000；50人约3.2个月，100人约1.6个月。广告每成交花$5时，15%下每单仅$7.7415，回收$2,000需259单；需先验证CAC，不建议先付费投放。

若把维护按每月2–6小时、每小时$20算，另需$40–120/月人时成本；20单场景收入254.83，扣这部分后仅134.83–214.83，尚未扣初始开发摊销和其他费用。这样的小项目只有持续新增、轻支持/低获客成本才有意义。

## 可执行的投入限制建议（尚未执行）

先限20小时，做离线照片→标注→一个PDF与保存恢复的完整路径；用自己拍的三个房间/20问题/多图/长说明对照Site Report Pro，检查图文对应、分页、速度与开始/完成步骤。此为验证建议，不是本轮已开始开发。

只有这一路径质量可过、且有清楚的购买理由/可触达的商店入口，再投入收费/更多兼容。若首版持续扩展到云协作、语音AI、复杂模板，则不再符合小成本小收益逻辑。推广/付费与真实用户实验需另定具体范围，不自动发消息或安装购买。

获客最大未知：每月能否持续得到新增付费者。现有评分和职业使用自述说明收费类别存在，不证明我们无需推广可卖出。若只能国内销售，先补地区需求/渠道；不能仅以少评分推无竞争机会。
