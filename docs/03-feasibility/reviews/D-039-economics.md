# D-039 月度经营情景模型

2026-09-12；依据[S-054](../../01-sources/app-store/2026-09-12/actor-economics-sources.md)及E-008。用户要求评估盈利，不代表立项。全部币种USD。

## 竞品目前情况

没有实际收入、付费人数、流失、成本数据，无法估计其真实净利润。千名演员为模糊累计用户自述。仅作假设演算：若恰好1,000名累计用户且其中当前30/50/100名付费，按月均6.4对应月摊销收入192/320/640美元，不是估计其当前真实收入，不能倒推出真实转化率。没有证据支持已稳定月赚数千美元。

## 成本依据

按每场景1,500字符：TTS每新场景约0.075–0.15美元，30场景2.25–4.50美元，仅合成费。免费两场景0.15–0.30美元/人；实际平均使用未测。重复播放应缓存。若大量人只用免费，成本独立于付费人数增长。年包月摊销5.83，按15%佣金扣除后约4.96；满用30场高价声音4.5后只余0.46，尚未计其他成本。不能默认高毛利或竞品就是此成本。

## 可复算基准（假设，非预测）

- 平均每个当前付费订阅月摊销收入6.40：约一半月付、一半年付，按已见标价舍入；不计积分包。年收款与摊销利润分开。
- 退款预留收入3%，Apple佣金15%（仅在符合并加入计划下）。不计销售税地区差异；实际应换成商店净收入。
- 付费每人每月生成/解析/重试等变动成本预算1.50：低于全部用满高价模型的压力情景；是需要测量实现的平均目标，不是报价。
- 每月1,000个新激活免费用户、每人平均变动成本0.20，共200；固定基础设施/工具预算100。不含额外付费广告。不同付费人数行故意维持同样免费获客预算，用于比较门槛，不是用户增长时间表。
- 月经营结余 = P×[6.4×(1−3%)×(1−15%)−1.5]−200−100，约3.7768P−300。
- 此结余不含开发者薪资、研发投入摊销、所得税；固定100不够实际费用时须增补。不是完整净利润。

## 压力与获客

若每付费人变动成本升至3美元，300人月结余383美元；若升至5美元，300人月结余约−217美元。每多1,000个免费激活用户、按0.2成本另减200；额外广告支出直接扣除。佣金改30%时300人约554美元，比基准少279。

为避免把累计安装等同订阅：稳态示例（不是行业基准），月流失10%、新激活到付费2%，300名付费需每月30个替补订阅，即1,500个新激活用户。此时免费变动预算应改为约300，不能沿用基准200。按新激活均计免费成本，稳态利润公式变为2.7768P−100；月结余1,000需约397名，3,000需约1,117名。未包含增长所需额外用户/广告与劳动。

## 我们的预算判断

没有演员受众流量/ASO增长数据，不能给期望月利润或成功概率。谨慎经营预算应把上线前3个月视为可能亏损或仅覆盖运营；不是统计预测。后续首个有意义目标是100–300名稳定付费者，在基准下月结余约78–833美元。若目标稳定数千美元，则需数百到上千稳定订阅与持续获客；现有证据不足以给它安排完整开发预算。保留待补证据，不以技术简单推收入高。
