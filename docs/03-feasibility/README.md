# 可行性筛选

输入是[第二阶段的候选](../02-candidates/INDEX.md)，不是原始榜单。对每个候选检查：输入获得、输出验收、自助程度、开发成本、处理/重试成本、维护支持、获客可行性、竞争差异。

当前没有通过本阶段的新项目。已有[出版与 Bubble 七项分析](reviews/narrow-workflow-opportunities-2026-09-10.md)为历史报告，后续 PDF 修复和 Bubble 深度维护已停止。

## 新评估记录模板

```text
候选 ID / 日期：
关联来源 / 已有竞品：
任务、明确输入、明确输出：
有代表性的输入如何低成本取得：
质量如何自行判断：
开发范围与时间估计（依据/未知项）：
单次成本、重试成本、人工支持与维护：
可核查的获客入口 / 市场规模证据：
相对现有方案的改进：
反证与失败条件：
决定：待补证据 / 待实验 / 暂缓 / 已停止
下一步以及停止条件：
```

不要求零竞品，也不把程序能够运行当可行性通过。成本未知时写未知，不编造预算数字。
