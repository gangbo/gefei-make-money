# D-048：四宫格发型的有限商业验证草案

2026-09-15。用户认可当前四宫格，询问如何判断值得做。本文件是建议方案，尚未执行、上线或批准广告支出；不新增已执行实验编号。复用S-064/S-065/S-066，没有新增外部市场数据。候选仍待补证据。

## 要回答的三件事

不同人物能否稳定交付；能否获得有发型意图的新用户并促成真实付款；扣除交付和获客后是否有贡献结余。单张好看和通用积分消耗不代表新增收入。

## 1. 有限质量与成本检查

先10张有许可、覆盖不同脸型/肤色/发长及轻微侧脸的输入，固定四宫格提示词；模拟输入与真实自拍分别统计。逐格检查本人辨识、发型符合、头发边缘/脸部畸变，轻微姿态变化可接受。建议门槛为10张中8张四格均可交付、每张最多重试一次；这是内部筛选门槛，不是统计可靠性证明。不达标先修提示或限定输入，不加风格库。

内置工具可继续看效果；生产每张费用、失败/重试计费和耗时必须从正式服务报价与实际日志核实，不能从内置调用推算。初始最多20次生成，到上限复盘。

## 2. 最小可收费页面

建议TikTomato独立发型页，限一张自拍→固定四种发型→一张四宫格下载。复用账号/积分/支付。先给真实样例，生成前说明价格与交付内容；不先免费交付完整结果再指望下载付费。已有余额按既有权益处理，与新增购买分开统计。价格根据实际成本及现有积分包核定，第一轮固定一个报价，不同时测多个价，不以降价为核心假设。

功能未就绪时只做明确标注的预告/兴趣入口，不收费，也不把点击计作购买验证。上线前需有真实交付与失败恢复。当前未实施这些修改。

## 3. 一轮有边界的实际使用实验

先选择一个可进入渠道，素材直接展示同一人物四种发型，引导发型专属页面；站内入口与外部发型意图流量独立归因。正式开发前先确认发布位置、规则与可获得访问的方法，避免上线后才找用户。自然渠道发布也计人工时间；广告金额另行明确，不在本方案中自动投放。

建议观察14天或累计200名去除机器人/内部测试的独立访客即复盘；不足200不判无需求，标记获客未验证。14天内新访客统一留7天付款归因窗再结算，较早触发200也照此处理。按渠道/新老用户分别记录：访问、价格展示、上传成功、收银台、付款成功、生成成功、下载、退款。核心漏斗使用同一访客队列，订单与付费人数分开。付款前流失不能当作已体验生成质量。

建议判断：200名有相关意图访客中，至少5名独立新付费用户且净交付贡献为正，可继续下一轮；1–4名则定位最大流失环节只改一项再测；0名且技术/支付正常则暂停该报价和渠道组合。均为限制投入的内部规则，不是行业基准，也不是证明可盈利；0/200不等于不存在需求。已有余额消费只计使用，泛积分新充值注明归因不确定，不能全部算发型带来。

贡献结余=归属本实验的实收收入−退款−支付手续费−所有付费/免费/失败/重试生成支出−获客支出−可变支持成本。另列开发工时、内容工时与固定成本，不称贡献结余为净利润。未消费通用积分还存在后续交付成本，不将全额充值当已实现毛利。
