# VocalDock 附加付费流程实验草案

> 后续更新：用户表示此前已经做过单次 4.99 实验且没有效果，生产环境仍有 2.99 包；当前要求暂停讨论 VocalDock，转向图片及垂直工作用途需求。本文保留为历史草案，不作为当前待执行计划；不假定此前实验与下文流程完全相同。

日期：2026-09-10。状态：可评审的建议，尚未实施；本仓库为知识库，本次未修改 VocalDock 产品。保持现有免费额度及原有工具权益。假设：部分去人声用户愿意为更方便的最终交付付费。

## 先找一个场景：最多七天

在成功处理的结果页、原下载入口之后展示一个可忽略的问题：“这份结果接下来主要用来做什么？”选项：唱歌/排练；剪辑/发布视频；乐器练习/混音；其他（可输入）；只是试试。

选择后可选回答：“接下来还需要用什么工具做哪一步？”不强制回答，不阻塞下载。按用户去重，记录来源工具，不把重复任务当多个用户。自愿回答有选择偏差，只用于选候选场景，不估计全体用户比例。

若已有足够的跨工具行为记录，可先用记录筛选，再用这个问题解释原因。没有足够回复时延长收集或定向招募同意联系的用户，不用日历到期冒充需求成立。未授权发送消息，本次不联系任何人。

## 一个可演示的候选方案

“排练伴奏一键导出”：复用当前分离结果，连续设置升降调、截取片段和淡入淡出，一次导出，不必重复下载和上传。

[公开首页](https://vocaldock.com/) 已有变调、剪切、卡拉 OK 等工具，此处验证的是跨步骤便利性，不是宣布这些能力缺失。需要先检查现有产品是否已提供同等流程；若已有，实验应改成曝光和引导，而非重复开发或收费。场景必须由前一步证据支持，不因举例而默认选择。

候选范围：一条不超过五分钟的音频；一套参数；一个 MP3 输出；结账前预览。格式、长度及处理能力须在上线前实测确认。不承诺音质优于原分离模型。

价格草案：一次 $4.99，明确非订阅。这是测试价，不是已证实的最优价格；先按最大允许任务核算处理、存储、支付手续费、退款和支持成本，不能覆盖则缩小范围或修改价格后再上线。保持试验期报价稳定，不同时测试多个价格。

已有订阅/点数权益必须核对，不对已经包含的能力重复收费；付费老用户单独统计。无法明确新增价值时停止此候选，不强行换包装收费。

## 结果页入口与交付

只给与场景匹配的成功任务结果展示附加入口，保留原下载按钮的可见性和顺序。

示例文案：“准备用这首伴奏排练？在一个流程里调整音调、截取片段并导出。单次 $4.99，无需订阅。”按钮：“查看示例与设置”。

未开发阶段只能展示明确标注“尚未上线”的演示及“申请测试”入口，不能伪装已可交付的购买按钮；申请和点击都不是付费证据。能可靠交付后再开启真实购买。若采用人工交付，必须写明人工处理、交付时间及失败退款条件，并纳入人工成本。

工程投入上限建议：首个可交付版本不超过 3–5 个开发日；这是限制范围的预算，不是工期承诺。超出则缩小流程或转为明确的人工试点。

## 统计口径

实验先在 Web 进行，Apple 单列。按同一个实验用户群统计，不混入未见过入口的历史买家：

附加入口实际曝光 → 打开设置 → 完成参数设置 → 发起结账 → 成功付款 → 完成导出 → 退款。

按去重用户报数，订单数另列。保存 experiment_id、user_id、source_tool、首次曝光时间、已有付费身份及订单关联；只收必要行为字段，不采集音频内容用于分析。

核心指标：曝光群体新增付费人数、净收入减去新增处理/支付/退款/支持成本后的贡献金额，以及每百名曝光用户贡献金额。这个金额不是全站利润，仍需覆盖原有免费成本和固定开支。点击率只用于定位掉点。

第一轮是小规模可行性试点，不声称证明全站收入增量。发现付费信号后，如样本量允许，再按用户固定随机分组保留对照，评估增量及原有购买是否被替代。不要用当前截图的混合队列直接充当对照组。

## 时间与判断

真实购买阶段建议运行 14 天，曝光不足时最多观察到 28 天；这些是投入边界。以下数量是探索用决策门槛，非行业基准或统计显著性要求：

- 未满约 200 名相关去重用户实际曝光：优先报告样本不足，不以零单判需求失败。
- 约 200 人曝光却几乎没人打开：检查场景匹配及入口是否真正可见，不开发更多功能。
- 有人完成设置但无人付款：检查报价清晰度、预览价值及结账错误；只针对主要障碍调整一次，不反复降价。
- 至少 3 名不同用户付款、成功交付且扣除变动成本后为正：允许继续小范围验证；不认定规模化盈利已经成立。后续跟踪退款及是否愿意再次使用。
- 满足曝光门槛、确认流程可用并调整一次后仍无付款：停止该候选，不外推为 VocalDock 全站没有商业价值。

同时监测原流程成功下载、报错、加载速度、回访及免费处理成本。如果附加入口干扰原流程则撤回入口；品牌查询趋势仅作观察，短期前后变化不能直接归因于实验。

4. 核查现有权益、交付可行性和单次成本，再上线最小付费版本。
