## 可得结论与限制

- 新注册群体中 77.6% 提交过任务，说明注册之后有较多实际尝试；不说明输出满意度或复购。
- 27 人购买环节参与量较小，但不能将 27/1,507 或 4/1,941 当作严格的同期群转化率：前后两段人群口径不同。
- 图示 14.8% 是当前口径的比率，混合了 Web 与 Apple 机制；不能直接认定为纯 Web 结账成功率。
- 任务完成仅代表系统状态，不证明结果达到用户预期；总任务数或每人平均任务数不能证明跨日留存。
- $17.96 是按说明估算的收入，不是核验到账金额或利润。未提供积分单位成本、固定成本、实际退款及支付费用。
- 低价包没有明显改善是重要的实际反馈，但缺少上线前后可比较队列，不能断言价格完全无关。

## 建议更新（未执行）

不再优先建议降价或增加一次性积分包，也不据此泛化增加工具。下一步只需定位付费需求未形成的位置：免费额度耗尽人数、满意结果获得情况、付费提示曝光人数，以及 Web 结账事件；按工具和渠道拆分，Apple 单列。

若免费额度足以完成多数一次性任务，下一次小范围实验应围绕免费体验和付费结果的边界；若用户未获得满意结果，先修结果质量；若已满意且看到付费条件仍没有购买，则应降低对该人群的投入预期，继续验证更强的新需求。新方向尚未被验证，不能因此承诺盈利。
