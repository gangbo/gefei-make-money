## B. 本地音频片段排练（新D-074）

- [Anytune Pro+ / Anytune Inc.](https://apps.apple.com/us/app/anytune-pro-studio-tools/id478293637)：$14.99下载，导出/遥控有额外内购；当前页面8.4K评分/4.9。变速/移调/命名片段/渐进练习/准备拍/文件导入/录音均已有。Dadmanator（2025-10-04）自述多年使用、早期从免费升级，主要移调适应声音与循环；不是新产品收入证据。
- [2026-08-05导入说明](https://anytune.zendesk.com/hc/en-us/articles/360021860472-Importing-songs-and-configs)及[设备间文件说明](https://anytune.zendesk.com/hc/en-us/articles/360026399692-Sharing-songs-across-devices)：可导入到Device或iCloud；源文件必须真正下载到本地。商店明确不能处理Apple Music订阅等DRM音频。iOS与Android流媒体能力不同，不能引用Android支持为iOS承诺。此为本地处理证据，尚未断网实测。
- [Amazing Slow Downer / Roni Music](https://apps.apple.com/us/app/amazing-slow-downer/id308998718)：$14.99，453评分/3.9，循环/变速/移调；[官网本地导入帮助](https://www.ronimusic.com/iphone_support.htm)列设备文件输入，但旧帮助的格式范围不当最新全兼容清单。商店提示Spotify不能用于此慢放用途；Apple Music支持有功能限制。2018教师标记/速度按钮建议是历史，不认定当前仍缺。
- [BeatLoop / OnBeat HQ](https://apps.apple.com/us/app/beatloop-loop-slow-dance/id6750597145)：音视频本地导入、段落链接、可听准备倒计时、循环间休息、速度递增、录制/同步回放与保存会话已有；内购$3.99/$24.99未注明周期，不能叫月/年/买断。完整离线未知。
- [OurDance / Ye Zhang](https://apps.apple.com/us/app/ourdance-dance-practice/id6767887549)：$9.99一次解锁；核心工具和一个保存项目免费；镜像/慢放/八拍校正/循环已有；可选本地分轨模型首次下载需联网。未足够评分不等于没人使用。舞蹈专用简化、倒计时与镜像不是产品空白。
- [Sonelune当前公开首页](https://sonelune.com/)为文本转语音与个人音频库，不能直接视为音乐片段排练已实现；原生App具体能力仍未知。已有VocalDock分轨不作为新项目；新候选核心为反复排练，首版不靠云分轨。
