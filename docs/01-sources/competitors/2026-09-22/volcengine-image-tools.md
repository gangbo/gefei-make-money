## 画质增强接口与限制

同步POST `https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/enhance-image`，MediaKit API Key的Bearer鉴权。支持HTTP(S)、mediakit、tos输入；PNG/JPG/JPEG/WebP，单图最多10MB。同步返回结果图URL，指南称有效24小时；生产持久化需核对另行发布的存储公告。

| 版本 | 输入 | 输出 | 倍率 |
| --- | --- | --- | --- |
| standard | 短边16–1440、长边16–2160 | 两边≤6144 | 1–8 |
| professional | 短边≥256、长边≤2048 | 长边≤10240 | 1–30 |
| max | 短边≥64、长边≤6240；长短比≤32 | 长边≤10240 | 1–30 |

`multiple`优先于目标宽高，未设默认2倍；专业/max支持`fidelity_first`和`generative_first`。大模型版建议目标控制在8000×8000以内以避免长耗时超时。生成式补纹理不是恢复真实缺失细节的保证；厂家示例分数不是我方效果测试。
