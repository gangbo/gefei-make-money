# D-082：PDF乐谱演出夹

- 记录日期：2026-10-14；阶段2 / 待补证据；DEC-073。
- 来源：[S-091](../../01-sources/competitors/2026-10-14/ten-app-candidates-evidence.md)。
- 优先平台：iPad优先，iPhone辅助。
- 具体任务：乐手把自己的PDF乐谱排成当场曲单，演出时稳定翻页、查看标注和跳转反复段。
- 已经观察到的证据：forScore美区约43K累计评分；商店有每周演出和1,100多份曲谱的长期使用自述。证明既有市场，不能说明我们能抢到用户或近期增长。
- 首版假设：PDF导入；曲目/演出列表；裁边；笔/文字标注；页码跳转；防误触演出模式；备份和导出。
- 改善假设：聚焦少量曲目的排练到演出切换，降低整理成本；基础跳转与曲单已有。需先确认窄版是否仍满足真正演出需求。
- 反证/未知：稳定性和无误翻页要求高；蓝牙踏板兼容、复杂标注、大PDF会增加成本。用户可能不愿迁移多年曲谱库。
- 成本判断：中高：十项里偏重，不能直接按$500完整复刻forScore。只读PDF演示不足以代表可上架质量。
- 获客假设：sheet music reader ipad、setlist PDF、digital sheet music binder；用自有/公版乐谱演示排练。未核ASO。
- 收费假设：$9.99–19.99买断；仅测试假设
- 下一次最小验证：公版PDF建10首曲单、长时间翻页标注再导出恢复；如果必须先补复杂踏板/识谱才能收费，延后此项。
- 实际实验/付款/开发结果：未执行。收入、增长或商业可行性未知；不以供给存在推定可盈利。
