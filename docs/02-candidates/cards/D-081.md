# D-081：车辆保养与维修档案

- 记录日期：2026-10-14；阶段2 / 待补证据；DEC-073。
- 来源：[S-091](../../01-sources/competitors/2026-10-14/ten-app-candidates-evidence.md)。
- 优先平台：iPhone，后续iPad。
- 具体任务：车主记录维修、保养、票据与里程，在下次保养或出售车辆时能拿出完整记录。
- 已经观察到的证据：近期KeepAuto商店版本历史、成熟车辆工具供给和长期使用讨论；没有这款新竞品的收入证据。
- 首版假设：车辆档案；维修/保养时间线；票据照片；日期/里程提醒；费用汇总；PDF/CSV导出与恢复。
- 改善假设：聚焦“我的保养记录”和卖车交接，录完票据即归档。离线、买断、导出均已有，不能当独占卖点。
- 反证/未知：免费及$1.99供给压低价格；需要持续手动输入；各车保养规则不同，应让用户设定而不承诺自动诊断。
- 成本判断：低至中：手动记录/本地提醒相对可控；OBD、GPS自动里程、车型数据库、联网推荐会显著扩大范围。
- 获客假设：car maintenance log、service history app、motorcycle maintenance record；记录到导出的演示。没有词量/转化证据。
- 收费假设：$4.99–9.99买断需强理由；仅测试假设
- 下一次最小验证：模拟一年12笔保养和票据，从迁入到导出，与KeepAuto比较；若只是换皮且更贵，暂不投入。
- 实际实验/付款/开发结果：未执行。收入、增长或商业可行性未知；不以供给存在推定可盈利。
