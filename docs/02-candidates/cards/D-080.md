# D-080：本地参考图板与项目素材包

- 记录日期：2026-10-14；阶段2 / 待补证据；DEC-073。
- 来源：[S-091](../../01-sources/competitors/2026-10-14/ten-app-candidates-evidence.md)。
- 优先平台：Mac，后续可考虑iPad。
- 具体任务：插画师、设计师、3D创作者把一个项目的参考图并排查看，保留来源说明，随项目归档或交接。
- 已经观察到的证据：PureRef有商业收费分层，Eagle买断提供广泛素材管理；尚无我们这个窄版的付费或迁移证据。
- 首版假设：拖入图片；缩放平移；自动排版；分组与文字；置顶查看；保存独立项目包；导出图板。
- 改善假设：让项目资料在一份可搬走的本地包内完整保存；先看竞品是否已经同样顺畅，便携性只是假设。
- 反证/未知：Freeform免费且系统自带，PureRef本来就简洁。若只是“无限画布放图片”，选择理由弱；大量大图内存和无损保存需测试。
- 成本判断：中：核心画板可控；大图库、浏览器采集、视频与AI搜索超出简单首版。
- 获客假设：reference board mac、moodboard offline、PureRef alternative；创作过程短演示。没有证实自然获客规模。
- 收费假设：$9.99–19.99买断；仅测试假设
- 下一次最小验证：50张自有图片建立图板，跨目录移动项目并恢复；检查引用不丢失、导出和交接步骤，与PureRef/Freeform对照。
- 实际实验/付款/开发结果：未执行。收入、增长或商业可行性未知；不以供给存在推定可盈利。
