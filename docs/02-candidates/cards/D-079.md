# D-079：本地音乐标签与封面批量整理

- 记录日期：2026-10-14；阶段2 / 待补证据；DEC-073。
- 来源：[S-091](../../01-sources/competitors/2026-10-14/ten-app-candidates-evidence.md)。
- 优先平台：Mac。
- 具体任务：收藏本地音乐、CD导入文件的用户批量修正专辑、艺术家、轨道顺序与封面，让播放器正确归类。
- 已经观察到的证据：Mp3tag具名付费产品；商店有CD收藏者的实际整理描述，官网给7个使用日试用。不是VocalDock音频降噪/分轨的重复项目。
- 首版假设：先MP3/M4A/FLAC；专辑分组；字段批改；封面替换；曲号；文件名与标签转换；预览、备份与还原。
- 改善假设：把“这一张专辑整理正确”作为引导，显示专辑艺术家不一致、曲号冲突和封面异常。不要把竞品已有批处理说成创新。
- 反证/未知：Kid3功能完整且免费；不同容器写回和保留未知字段需要验证。商店旧评论提撤销困惑未复现，不据此声称竞品缺撤销。
- 成本判断：中：成熟标签库可减少代码量，格式兼容与数据保全是主要工时；不承诺所有音频格式。
- 获客假设：mp3 tag editor mac、fix album artist mac、batch album artwork；本地音乐收藏、CD整理具体教程。搜索量未核。
- 收费假设：$9.99–14.99买断，免费单文件完整流程；仅测试假设
- 下一次最小验证：自制30首带不同封面/曲号/多艺术家字段的测试文件，修改前后比较音频流、标签和播放器归类；再比免费工具的完成步骤。
- 实际实验/付款/开发结果：未执行。收入、增长或商业可行性未知；不以供给存在推定可盈利。
