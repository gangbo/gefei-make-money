# D-078：家庭物品档案与搬家箱清单

- 记录日期：2026-10-14；阶段2 / 待补证据；DEC-073。
- 来源：[S-091](../../01-sources/competitors/2026-10-14/ten-app-candidates-evidence.md)。
- 优先平台：iPhone / iPad。
- 具体任务：家庭用户给储物箱、房间里的物品拍照建档，搬家后能查到放在哪里，并导出物品清单。
- 已经观察到的证据：Itemlist的TrustMRR页声明连接RevenueCat，当前标题近30天收入$995、正文MRR $666。比只有标价的证据更直接，但不代表净利润或单机买断版收入。
- 首版假设：房屋→房间→箱子；连续拍照录入；名称/数量/照片/备注；搜索；箱码生成；PDF/CSV导出；本地备份恢复。以“物品在哪”作为主流程。
- 改善假设：尝试让一次连续录入和装箱更快，扫码即可看箱内清单。扫码/层级/买断已有，优势必须来自同样30件物品的实际完成速度。
- 反证/未知：初次建档需要用户投入；共享家庭场景可能要求云同步；图库体积和备份可靠性比表单本身重要。Nest Egg低价买断是直接反证。
- 成本判断：中：无协作/联网商品库时，有希望按$500简单首版目标控制；多端实时协作应单独估算。
- 获客假设：home inventory app、moving box inventory、storage box organizer；装箱前后演示及搬家清单内容。词量和转化未查。
- 收费假设：$9.99–19.99买断，免费少量物品；仅测试假设
- 下一次最小验证：自己录入30件物品、分3个箱子，盲找10件并导出/恢复一次；对照免费Itemlist流程。若录入没有更省事，就不靠换UI进入。
- 实际实验/付款/开发结果：未执行。收入、增长或商业可行性未知；不以供给存在推定可盈利。
