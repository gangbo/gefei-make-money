# D-084：跨应用文件拖放暂存架

- 记录日期：2026-10-14；阶段2 / 待补证据；DEC-073。
- 来源：[S-091](../../01-sources/competitors/2026-10-14/ten-app-candidates-evidence.md)。
- 优先平台：Mac。
- 具体任务：用户从多个文件夹收集附件或素材，暂存在浮动架子里，再一次拖到邮件、聊天或目标文件夹。
- 已经观察到的证据：Dropover有明确收费/试用、持续维护和用户购买自述；不是新空白，未核当前销量。
- 首版假设：快捷键呼出；多文件暂存；分组；Quick Look；批量拖出；操作后清空；文件失效提示。
- 改善假设：尝试以准备一包附件为固定流程，让收集和检查更顺手。竞品已有分组和快速操作，不能预设我们更简洁。
- 反证/未知：客单价低、成熟竞品强；不同应用拖放、文件被移动后的引用、多显示器和系统升级都会产生维护。
- 成本判断：中：原型短，拖放兼容和行为可靠需要反复验收；完整Dropover云分享不计入单机方案。
- 获客假设：drag drop shelf mac、collect files attachments；10秒实际拖放演示。自然曝光和付款转化未知。
- 收费假设：$4.99–7.99买断；仅测试假设
- 下一次最小验证：从Finder/浏览器/截图收集，再拖到邮件和文件夹，覆盖文件被移动/删除的情况；如果没有明确新选择理由，不用低价强推。
- 实际实验/付款/开发结果：未执行。收入、增长或商业可行性未知；不以供给存在推定可盈利。
