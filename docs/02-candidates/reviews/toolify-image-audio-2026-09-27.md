# Toolify 图片/音频定向扫描：值得继续看的任务

2026-09-27。证据：[S-077目录人工摘要](../../01-sources/rankings/2026-09-27/toolify-image-audio-scan.md)、[S-078官方核查](../../01-sources/competitors/2026-09-27/toolify-image-audio-official-check.md)。这是阶段1发现与现有候选对照，不新增 D 编号、不改变72项状态或 DEC-055 的当前顺序。Toolify 收录和竞品标价是**供给/可售线索**，不是我们可盈利的证据。

| 暂定次序 | 狭窄任务与承载 | 为什么值得再看 | 最大缺口 / 下一次最小验证 |
| --- | --- | --- | --- |
| 1 | **歌曲指定词洁净版**：上传歌曲，自动标时间，用户勾选保留/处理，导出洁净版与伴奏；可先评估为 VocalDock 的独立工具页 | SongCleaner 说明了可审核流程；已有分轨能力可能复用，交付比泛音频编辑明确 | 需要有权使用的样本，同一首歌测识词、时间边界、听感、重试成本；查独立需求词和竞品业务页。不要把“降噪”当相同功能 |
| 2 | **单旋律音频→MIDI**：优先干净人声/单乐器，30秒预览与标准 MIDI 导出；可能是独立页面，不默认并入 Sonelune | PureMIDI 有清楚的积分收费边界；输入/输出客观，容易做有限质量测试 | 多乐器整曲别列首版；查模型/API成本、单音/节奏准确率和用户是否真的要编辑而非听歌；对照免费替代和搜索量 |
| 3 | **同风格游戏 UI 小套件**：参考图+有限组件（按钮/面板/图标）+规范化尺寸/透明图层/ZIP | ForgeGUI 已展示整套交付；与旧 Blender 3D 构想不同，可从 2D 资产切入，贴近 D-065 的“可编辑产物”问题 | 竞品已有成套且有导出；必须验证引擎内可用和文本/图标一致性；先查付款/流量，不直接做通用生成器 |
| 4 | **电商 SKU 批量一致性图片**：白底/背景/尺寸/命名/打包，优先已有真实商品图；属于 D-003/004 的条件复查 | Pebblely 有实际批量收费、厂商自述付费使用；适合 TikTomato 现有图像能力扩展 | Pebblely/Flair 已覆盖批量，旧候选因质量返修和差异不足暂缓。只有发现受约束、可低成本验收的剩余步骤，才重开 |
| 5 | **播客口头禅/返工段清理**：作为 VocalDock 可能的附加流程 | Cleanvoice 可拆分处理且有 API；可能复用现有音频上传流程 | API 已廉价，缺选择理由；复杂多轨/视频剪辑不适合首版。Sonelune 定位未核 |

这轮不优先：通用生图/TTS、单条文字生成音效、换背景/放大、老照片修复、证件照和全自动母带。前几项与自有或成熟供给重合；后两项虽可做，但目前缺可进入渠道、质量优势或反复购买证据。**有竞品不是排除理由**，这些只是本轮资源次序。

下一步按 DEC-028 先查第1/2项的竞品业务页、Semrush 历史与独立意图词，之后才决定是否分配候选卡并做同输入样本。第3项查引擎导出细节与购买线索。未做生成、付款、开发或上线。
