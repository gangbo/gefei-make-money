# Tarkov Documents Map：站点与商业模式分析

日期：2026-09-11。依据：[S-033 资料与图片](../../01-sources/competitors/2026-09-11/tarkovdocsmap/source-notes.md)。用户要求分析该站，以下商业判断为助手分析，不代表用户决定开发。未完成交互实测。

值得借鉴的是：在新游戏机制出现后，把分散信息整理成玩家对局中可反复查询的工具。公开反馈支持它解决了具体使用问题；截图中的百万访问和广告配置尚不能证明稳定利润。

## 1. 它解决什么任务

用户是《逃离塔科夫》Kord Breach 战斗通行证玩家；任务是找到所需文档、确认位置和钥匙要求，再推进奖励。本站将相关资料集中在交互地图上，另有奖励追踪和纠错入口，见[官网](https://tarkovdocsmap.com/)。

核心改进是把“按物品翻资料”改成“围绕当前地图完成搜索任务”。[发布帖评论](https://www.reddit.com/r/EscapefromTarkov/comments/1vkb7re/loot_i_made_a_documents_tracker_map_site/)中的玩家明确比较了 Wiki 多页切换与按地图集中查询。这比泛泛称赞界面漂亮更能解释产品价值。

推断：同一玩家可以在多次对局重复使用；社区报点能扩展数据，但仍需复核。尚无用户队列证明留存率，也没有把重复使用意愿当作订阅意愿。

## 2. 增长线索

截图标注的 2026 年 8 月估算如下，不是官方统计：

| 渠道 | 截图占比 | 假设总访问 108 万成立时的访问量 |
| --- | --- | --- |
| Direct | 59.21% | 约 63.95 万 |
| Social | 20.58% | 约 22.23 万 |
| Search | 10.38% | 约 11.21 万 |
| Referrals | 8.03% | 约 8.67 万 |

Direct 与 Social 合计 79.79%。这组结构不支持将主要增长归因于长尾自然搜索；Search 也未拆分品牌词、自然与付费搜索。Direct 不能直接等同老用户：书签、手输网址及缺失来源归因等都需要后台区分。

可观察的传播入口包括作者的 Reddit 发布帖，以及[其他用户在 Steam 回复中推荐本站](https://steamcommunity.com/app/3932890/discussions/1/580554442217112150/)。后者提问者说推荐不解决其具体问题，因此仅作为外部提及证据。

较合理但尚未量化验证的路径：新玩法带来集中查找需求 → 作者发布可用工具 → 玩家推荐与补充数据 → 反复打开，并可能产生品牌搜索。不能从截图中的出站 X/Reddit 链接反推出这些平台贡献的流量。

域名注册时间由[Verisign RDAP](https://rdap.verisign.com/com/v1/domain/tarkovdocsmap.com)确认为 2026-08-10，属于新域名。图片的“28 天”是历史时点；图表 6、7 月为零也不能单独算作业务增长证据。8 月估算只覆盖上线早期，未知活动热度消退后的水平。

## 3. 变现与收入边界

已经核实[公开 ads.txt](https://tarkovdocsmap.com/ads.txt)与首页 publisher ID 与截图一致；官网有支持服务器费用的入口，Reddit 有一条玩家自述已捐款。广告实际投放、捐款金额、营收与净利润均未知。[Google 的说明](https://support.google.com/adsense/answer/12170222?hl=en)区分 ads.txt 授权与站点状态，不能把有 ID 当作收入证明。

仅作算术敏感性分析：如果截图的访问和每次浏览页数均准确，且与收入使用同一 PV 口径：

```text
假设月 PV = 1,080,000 × 2.04 = 2,203,200
假设广告收入 = 月 PV ÷ 1,000 × 页面 RPM
```

| 任意假设的页面 RPM | 条件性月广告收入 |
| --- | --- |
| $1 | 约 $2,203 |
| $3 | 约 $6,610 |
| $5 | 约 $11,016 |

这些 RPM 不是本网站实测或游戏行业基准，三个结果也不是收入预测区间。公式按[Google RPM 定义](https://support.google.com/adsense/answer/190515?hl=en)。实际需要同周期有效流量、地区、广告展示与收入；页面长时间停留不自动带来更多有效广告展示。未扣基础设施、维护和其他成本。

判断：有免费工具加广告/赞助的商业路径，但没有订阅需求或盈利验证。不能把高使用价值直接换算成高付费转化。

## 4. 真正投入与竞争

[作者自述](https://www.reddit.com/r/Tarkov/comments/1vkb18p/i_made_a_documents_tracker_for_the_kord_breach/)花约 7 小时做初版，最初仅覆盖部分地图。这个数字不代表当前完整产品工时，也不包含后来持续整理点位、响应问题和维护网站的工作。

工程判断：地图展示、筛选和本地进度可以用常规网页技术实现，主要查询不必逐次调用 AI。相比生成型产品，可能减少按次模型成本；总成本仍取决于图像流量、提交审核、数据更新和运维，不能据此宣称成本趋近于零。

已有[Tarkov Farm](https://tarkov.farm/)直接覆盖同一任务，首页展示 12 张地图和 210 个点位。其他替代还在社区评论中出现，但本次没有做完整比较。竞争存在不构成淘汰理由；真正需要比较的是玩家为何选择新站：布局是否更好用、数据是否及时、有没有可信传播入口。

复制页面相对容易；复制玩家信任、资料积累和更新速度更难。新赛季会创造窗口，也可能让旧资料与流量失效。这里的持续维护是业务工作，无法用初版代码量衡量。

## 5. 对当前选品的意义

对用户有参考价值的方向是“明确人群的反复查询工具”：输入多可公开取得，交付自助，技术范围容易收窄，也存在可观察的社区入口。用户已有游戏相关流量站经验可以作为背景，但不能推断两个游戏用户能直接互相导流。

它成立的理由无需是 AI 推理。若未来采用 AI，应先用于后台整理投稿、翻译或检查重复，并保留事实复核；这是可能的实现方案，不是本站已验证的提效数据。

助手建议：保留为商业模式样本，目前证据不足以支持直接照抄同游戏同任务。若继续考察同类新机会，先明确具体游戏/新机制、反复问题、可复核资料和现有工具不足，再做单地图或单任务的小范围验证；收入判断至少需要匹配周期的广告数据或可信经营披露。用户未要求寻找下一游戏或开发原型，本轮不执行这些后续事项。
