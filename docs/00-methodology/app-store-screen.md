# 跨国App Store选品路线

2026-09-13范围更新（DEC-047）：以[面向所有用户的跨榜单选品](broad-market-discovery.md)为准，解除小型B端/职业效率限制。下方历史采样及优先级不再限制新线索人群。

2026-09-12用户新增授权，DEC-033。目标是功能聚焦、可小团队交付、已有付费需求的App；可借鉴任务/商业模式，不以强加AI为前提。

1. 先选市场及分类：首批美国、日本、德国，iPhone效率类付费榜；后续商业、摄影/视频、工具分类及英国/加拿大/澳大利亚按缺口追加。榜单国家是销售市场，不是开发者国籍。
2. Paid是付费下载榜，免费榜可能含订阅，不把任一榜当收入。保存国家、设备、分类、日期、榜位、App ID和已读范围。
3. 收入分层：接口验证/可追溯开发者披露；第三方估算注明周期和市场；标价、评价、榜位仅线索。不能将用户量或评价数乘单价当收入。
4. 功能小与开发简单分开：检查硬件依赖、离线、系统集成、数据许可、当地规则、维护和支持。不靠页面数量判断成本。
5. 对照核心人工劳动与完整现有方案，优先相机/现场录音/本地文件/系统快捷入口等手机使用理由；AI须有可检查的节省步骤。
6. 获客先看App Store地区排名历史、近期评价、ASO词/竞品与渠道。Semrush只补网站获客，低网站流量不淘汰主要通过商店分发的App。
7. 原始榜单进入01-sources/app-store；初筛报告进02-candidates/reviews；先去重再分配D编号。进入可行性后才定义实验，不自动安装/付款。

当前资料只够建立线索池，未证明盈利；不要求联系用户为研究前置。教程D-028保留当前进度，旧暂停方向不因新来源自动重启。
