# PuzzleBento 28 天投稿日历

整理日期：2026-11-23（America/New_York），落地页与关键词分配补于 2026-11-24。**本表只排 [puzzlebento.com](https://puzzlebento.com/)**，不排另外四个站。

计划：28 天 × 每天 5 个不重复平台（2 个大站 + 3 个小站）= **140** 个平台。游戏投稿站和大站靠前。婚礼、教师、发票、问卷等不契合渠道未硬凑。

建议起始日：2026-11-24 至 2026-12-21（America/New_York）。若改期，保持「第 1 天」的平台顺序即可。

## 关键词与落地页规则（必读）

推广不要用同一套关键词覆盖全部平台，改用网站上的不同游戏分别带链。

- 每个平台只分配一个目标落地页：尽量是具体游戏页，而不是永远指向首页。
- **首页链接不超过 20%。** 本表 140 条里首页 22 条（约 15.7%），主要用于 Product Hunt、Show HN、YouTube、GitHub、资料页等更适合介绍整个合集的入口。
- **同一天不要重复同一个游戏**（同一天可以有多条首页，因为首页不是某款游戏）。
- 热门游戏可以多分几次，但 **单款游戏不超过总数的 15%。** 本表最多的是 Sudoku，12 次（约 8.6%）。
- **锚文本要多样化**：品牌词、URL、游戏名、长尾词混用；**同一个锚文本最多出现 3 次。**
- 日语平台用 `/ja/` 或 `/ja/games/…/`；葡萄牙语平台（SAPO）用 `/pt/`。
- 繁体中文平台：站点**没有**独立繁体路径。官方只有 `/zh/`，页面 `html lang="zh-Hans"`，可见标题为简体（已用 GET 确认 200）。本表仍把繁中平台链到对应的 `/zh/` 游戏页，文案请用 [submission-copy.md](submission-copy.md) 的繁体稿，不要发明 `/zh-tw/` 之类的地址。
- 法语、德语、韩语、意大利语、西班牙语等平台链到英文游戏页，文案可用英文游戏短描述；若要开场白，可参考文案页里已有的法/德/韩/意合集短描述，但锚文本按本表填写。
- 全部游戏 URL 均来自 [sitemap.xml](https://puzzlebento.com/sitemap.xml)，并已逐条 GET 确认 HTTP 200。未编造地址，也未编造搜索量；热度仅根据 2026 年公开盘点是否常点名该玩法，判断不了的标「热度未知」。
- 文案列指向 submission-copy.md 里对应游戏的英文 / 日文 / 繁中短描述。感恩节找词排在日历前几天的博客（2026 年感恩节为 11 月 26 日，纽约时间）；圣诞节找词排在后半段。

## 怎么用

- **大站**：游戏投稿/展示平台、大型游戏论坛或媒体、以及 YouTube / GitHub / Product Hunt / Show HN 这类高曝光入口。
- **小站**：博客、资料页、Mastodon、书签、较小的垂直社区或排队目录。
- 先读版规再发。同一天不要五份完全相同的简介。Product Hunt 与 Peerlist 已错开。Show HN 排在周一（第 7 天），不要拉票。
- itch、Game Jolt、indiexpo、Y8 等是托管分发，请同时在资料页填写官网（本表已指定具体游戏或首页，按落地页填写）。ふりーむ允许 HTML5，但游戏内不能跳出到外站。
- js13kGames 仅在有符合体积限制的作品时再交；Godot 论坛仅在有 Godot 导出时再发。做不到就空过，不要改投不相关的站。
- 勾选可记在 [submission-tracker.md](submission-tracker.md)。优先级说明见 [submission-priority.md](submission-priority.md)。游戏文案见 [submission-copy.md](submission-copy.md)。
