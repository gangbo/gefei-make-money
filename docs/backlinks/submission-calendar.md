# PuzzleBento 28 天投稿日历

整理日期：2026-11-23（America/New_York）。**本表只排 [puzzlebento.com](https://puzzlebento.com/)**，不排 ChartSeat、Online Poll Maker、InvoiceNeat、TikTomato。

计划：28 天 × 每天 5 个不重复平台（2 个大站 + 3 个小站）= **140** 个平台。已从总库可用渠道里按「和小游戏 / 网页解谜的契合度、以及 P0/P1 优先级」筛选；游戏投稿站和大站排在前面。婚礼、教师、发票、问卷、软件目录、职业社交（LinkedIn/Xing）等不契合的站没有硬凑进来。

建议起始日：2026-11-24 至 2026-12-21（America/New_York）。若改期，保持「第 1 天」的平台顺序即可。

文案用 [submission-copy.md](submission-copy.md) 里 PuzzleBento 的英文稿；日语/繁体渠道改用同页的日文或繁中稿；法语、德语、韩语、意大利语渠道用该页对应语言短描述。论坛帖用文末非广告模板，只保留解谜/游戏相关的句子。

## 怎么用

- **大站**：游戏投稿/展示平台、大型游戏论坛或媒体、以及 YouTube / GitHub / Product Hunt / Show HN 这类高曝光入口。
- **小站**：博客、资料页、Mastodon、书签、较小的垂直社区或排队目录。
- 先读版规再发。同一天不要五份完全相同的简介。Product Hunt 与 Peerlist 已错开。Show HN 排在周一（第 7 天），不要拉票。
- itch、Game Jolt、indiexpo、Y8 等是托管分发，请同时在资料页填写官网。ふりーむ允许 HTML5，但游戏内不能跳出到外站。
- js13kGames 仅在有符合体积限制的作品时再交；Godot 论坛仅在有 Godot 导出时再发。做不到就空过，不要改投不相关的站。
- 链接属性仍为未知，见 [submission-priority.md](submission-priority.md)。勾选可记在 [submission-tracker.md](submission-tracker.md) 或自己的表格。

## 总览

- 已排入：**140** 个不重复平台（推荐-免费可用 82，可用-有门槛 58）。
- 未列入但同属可用的渠道：引擎专用论坛（Unity / Unreal / Construct / RPG Maker，除非作品确实用该引擎）、协会名录、众筹、托管/SDK 色彩过重且几乎回不了官网的分发网（Poki、CrazyGames 已排除；GameDistribution 等也未排入）、以及发票/婚礼/教师/问卷等不契合站点。
- 若某一天的站当时无法提交（排队、注册关闭、赛期未到），记下原因并延后，不要用无关平台顶上。
