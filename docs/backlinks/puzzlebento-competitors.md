## 4. 若有 Ahrefs／Semrush 导出，如何再洗一轮

公开搜索的遗漏会很多，尤其是新站。若要对某一个最像的对手做深挖（建议优先 PuzzleKite、Play Puzzles 或 Logic Puzzles Online）：

1. 导出该域名的 Referring domains 或 Backlinks CSV（含来源 URL、目标 URL、锚文本、`rel`、首次／最近发现日期）。
2. 去掉：竞品自己的子域、明显 scraper／镜像、已 404 的来源、用户生成垃圾、以及 Reddit。
3. 对剩下的来源域名逐个打开：是否还在线、是否还有那条链接、是否允许普通用户免费注册／提交／发帖。
4. 只把「仍在线 + 链接仍在 + 已确认免费可提交」的项补进 [free-directories.md](free-directories.md) 和 [submission-tracker.md](submission-tracker.md)。
5. 付费、价格不明、或只能编辑联系的百科／媒体，放入排除说明，不要混进提交表。

把 CSV 放到工作区后，可以按上面规则批量清洗，再人工抽查通过项。
