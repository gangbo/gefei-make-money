# 纯免费外链渠道总表（2026-11-19 核实）

只收录 **官方页或官方帮助页已确认存在免费通道** 的渠道。可选的付费加速若存在，会在条件里注明，但不作为提交前提。未写入任何未核实的 DR，也不把站点自评的 dofollow 写成已实测属性。

核验时区：America/New_York。适用站点简称：PuzzleBento、Chartseat、Online Poll Maker、InvoiceNeat、TikTomato。
